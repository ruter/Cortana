## 2025-02-19 - Dependency Management in Optimization
**Learning:** Even if a library is in `requirements.txt`, using `run_in_executor` with the standard library is preferred by some reviewers for file I/O to minimize dependencies and maintain simplicity.
**Action:** Prefer standard library solutions (like `run_in_executor`) for async I/O over external libraries unless the external library offers significant additional value.
## 2025-02-21 - Asynchronous File I/O Optimization in Coding Tools\n**Learning:** In Python's `asyncio`, performing standard file I/O operations (like `open()`, `read()`, `write()`) within an `async def` function directly blocks the main event loop, significantly degrading performance, especially for large files. To make file I/O truly non-blocking without adding external dependencies (like `aiofiles`), you should wrap these operations in a synchronous helper function and execute them using `asyncio.get_running_loop().run_in_executor(None, ...)`.\n**Action:** When creating or modifying `async` file I/O tools, always offload the actual blocking I/O calls to a thread pool via `run_in_executor` to preserve the responsiveness of the event loop.
